#Password Generator Using Python

* About the Project

This is a simple Password Generator project made by using Python.

The program ask the user to enter the required password length and then generate a random password by using letters, numbers and special characters.

* Features

. Generates random passwords
. User can choose the password length
. Uses letters, numbers and special characters
. Simple and easy to use
. simple Python project

* How the Program Works

First the program ask the user to enter the password length.

If the length is less than 4, then program will displays an error message.

If the length is valid, then program will select random characters from letters, numbers and special characters and generate the password.

Finally, the generated password is displayed.

* Formula / Logic

There is no mathematical formula used in this project.

The password is generated by randomly selected characters from:

. Letters
. Numbers
. Special Characters
